# Autonomy Log

- Status: created in Phase 2, empty by design
- Human-facing record. Never loaded into a model prompt.

## What this file is for

Autonomy is earned, and only autonomy over external action. A workflow that
takes no external action is GREEN at birth, because nothing leaves the building
and there is nothing to review. Every workflow that produces something external
enters at YELLOW, without exception.

Promoting one of those to GREEN requires a documented window at 90 percent or
better workflow success and 80 percent or better output acceptance, recorded
below with the date and the numbers. Nothing is promoted on a hunch, and an
entry without both figures is not a promotion record.

The third approval level is not a higher tier of autonomy. It is the set of
things this system does not do: money, contracts, pricing, commitments,
sensitive relationships, and anything sent to a current client family. No
workflow is ever promoted into it, and no code path implements it. The runtime
approval type has two members for that reason, so such a workflow cannot be
constructed at all.

## Promotions

None. No workflow has produced an external artifact yet, so there is nothing to
